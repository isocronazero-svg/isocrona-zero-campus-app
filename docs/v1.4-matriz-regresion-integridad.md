## Controles de integración
- Relación: cuenta → socio → inscripción → curso → justificante → pago → certificado de inscripción.
- Relación: curso → instructor → asistencia → diploma.
- Relación: socio → módulo de test → intento → resultado.
- Relación: socio → cuota → justificante → validación → auditoría.
- Baja de curso: no borrar historial, no confundir baja con devolución ejecutada, conservar auditoría y liberar plaza conforme a reglas existentes.
- No reutilizar cuentas, credenciales, documentos ni bases de datos reales en la demo.
- Verificar comportamiento en Android, iOS Safari y escritorio; menús sin opciones ocultas por scroll horizontal.
