# V1.2 - tesoreria de formaciones

Incremento acotado de simplificacion administrativa.

La vista prioriza pagos pendientes e incidencias. Mantiene visibles persona, formacion, socio/no socio, importe, justificante y estado. Las acciones frecuentes siguen accesibles y el detalle secundario queda agrupado en Mas detalles.

La cuenta oficial de pago queda centralizada como valor por defecto para nuevas formaciones. Solo se rellena cuando el campo esta vacio y sigue siendo editable para una formacion concreta.

El gate check:app incorpora regresiones especificas para cuotas, tesoreria de formaciones y cuenta de pago por defecto.

No desplegar directamente a main o produccion. Integrar primero en feature/v1.2 tras CI verde.
