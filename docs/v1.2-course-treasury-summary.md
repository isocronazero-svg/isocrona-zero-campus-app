# Resumen

El bloque de tesoreria V1.2 busca que la persona responsable pueda resolver la operativa diaria con menos pasos. La pantalla abre sobre pendientes, permite saltar a incidencias y conserva justificantes, validacion, reversion, socio/no socio, importes y trazabilidad.

La cuenta de pago oficial se propone automaticamente cuando el formulario de una nueva formacion expone un campo de cuenta vacio. Sigue siendo editable y nunca sustituye una cuenta especifica ya informada.
